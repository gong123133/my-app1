# 蛛迹 · 野外蛛形动物采集记录（v2）

手机优先、离线可用的网页应用（PWA），用于蛛形动物采集记录。

v2 的核心变化：**主记录方式改为“科 → 属 → 种”逐级选择**，任意一级都可以点 `sp.` 直接记录；语音降为辅助；记录编号可手动修改；内置中国蜘蛛与盲蛛名录。

---

## 一、怎么用（主流程）

1. **设置**：填采集人、地点；需要时手填温湿度/坐标。
2. **采集 → ＋ 记录一条**：
   - 选**科** → 进入属列表 → 选**属** → 进入种列表 → 选**种**；
   - 任意一级点右侧 **`sp.`**，直接记到这一级（如“园蛛科 sp.”、“Argiope sp.”）；
   - 顶部搜索框输入科/属/种/拉丁名，可**直接跳到种**，不用逐级点。
3. **记录表单**：数量、性别/虫态、生境、方法、备注、照片；**记录编号自动生成，也可以手动改**。
4. **统计 → 生成日报 PDF**：A4 日报 + CSV。

语音仍然可用：开始采集后说 **“横纹金蛛三头”**，直接记一条；说 **“结束采集”** 收工。语音只是辅助，听不清时用逐级选择，不会写错。

## 二、内置名录（v2）

| 类群 | 科 | 属 | 种 |
|---|---|---|---|
| 蜘蛛 | 72 | 892 | 5875 |
| 盲蛛 | 43 | 166 | 1521 |

- 蜘蛛数据来自《中国蜘蛛名录（陆千乐整理，2023-01-12）》。
- 盲蛛数据来自 `盲蛛.docx`；其中 **7 个科有 species 级记录**，其余 36 个科目前只有科名/属名，已保留“科 sp.”“属 sp.”入口，等后续补充。
- **蜘蛛的科中文名只收录了常用科**；未收录的科在界面上显示拉丁名（如 `Caponiidae`），不影响按拉丁名检索和记录。
- 蜘蛛的属中文名原始表里没有，属级显示拉丁名；种级有中文名。

## 三、换成自己的名录

“设置 → 分类名录”支持两种方式：

1. **粘贴 CSV**；
2. **选择 CSV 文件**（替换或合并）。

列顺序（8 列）：

```
类群,科中文,科拉丁,属中文,属拉丁,种中文,种拉丁,别名
```

- 别名用分号 `;` 分隔，可留空
- 只到属：种中文、种拉丁留空
- 只到科：属、种都留空
- 旧版 7 列（没有“类群”）仍可导入，默认归为“蜘蛛”

“替换”会整体替换；“合并”按“类群+科+属+种拉丁”去重合并。

## 五、定位说明

- 浏览器只在 **HTTPS 或 `http://localhost`** 下允许定位；双击 `index.html`（`file://`）会失败。
- 打开“＋ 记录一条”时会自动请求定位；也可以先点“开始采集”。
- 手机需允许 Chrome 使用定位；电脑 Edge 还需要 Windows 设置里打开“定位”。

## 六、已知边界

- **语音识别**：浏览器 Web Speech API，安卓 Chrome 需联网，境内可能因服务不可用而失败；语音只是辅助，文字/逐级选择始终可用。
- **海拔**：优先 DEM（约 90 m 分辨率），其次 GPS；误差约 ±10–30 m。
- **天气**：Open-Meteo 在线获取；无网络时手填。
- **PDF**：调用系统打印，选“另存为 PDF”。
- **照片**：存在浏览器 IndexedDB，不进入 JSON 备份，也不进入 PDF。
- **数据**：保存在“浏览器 + 网址”里；换网址/清缓存会丢，务必每天导出 JSON 备份。
- **坐标系**：WGS84；与国内地图底图叠加时注意 GCJ-02 偏移。
